Why Asmory · Why now?

AI changes the economics of low-level programming.

Assembly used to trade maximum control for maximum human cost. AI lowers that cost, and Assembly gives an agent an unusually short path from generated code to measurable machine behavior.

01 / DIRECT

Concrete optimization targets

Instructions, register pressure, dependency chains, SIMD width, memory access and cycles are directly visible to the tuning loop.

02 / FAST LOOP

Edit → assemble → benchmark

For small kernels, fewer high-level compilation stages make aggressive AI iteration practical.

03 / ECOSYSTEM

Stop regenerating every kernel

Give humans and agents a registry of reusable machine-level building blocks with explicit ISA and ABI contracts.

In the AI era, Assembly may finally deserve a modern package ecosystem. Asmory exists to find out how far that idea can go.

Compatibility is a dependency.

高级语言通常把 CPU 特性藏在编译器后面。Asmory 反过来：机器能力就是包解析的一部分。

Why this model →
01 / RESOLVE

ISA-first resolution

版本解析同时检查 architecture、ISA baseline、extensions、ABI、object format 与 assembler 能力。

02 / LINK

Section-level dead code GC

函数与常量按独立 section 组织，最终由 linker 依赖图和 --gc-sections 清除未使用机器码。

03 / CONTRACT

Machine-readable ABI

导出 symbol、calling convention、stack alignment、clobbers 等进入 manifest，让人和 LLM 都能可靠调用。

A registry, not a source forge.

Develop code wherever you want. Asmory stores the versioned package record that resolvers can trust: Project → Release → Variant → Artifact.
