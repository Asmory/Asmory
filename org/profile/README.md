# Asmory

**Packages for the instruction level.**

Asmory is building an Assembly package ecosystem where ISA versions,
extensions, ABIs, object formats and machine Variants are first-class parts of
dependency resolution.

### Why?

AI-assisted development has changed the economics of writing and maintaining
low-level code. Asmory explores what becomes possible when reusable Assembly
can be discovered and consumed with package-manager ergonomics without hiding
the machine contract.

### Current work

- Assembly-native registry server
- Linux x86-64 Assembly CLI
- CPUID/XGETBV host target detection
- x86-64-v1/v2/v3/v4 classification
- ISA/ABI/Variant specification
- package index and resolver design
- linker-oriented dead-code elimination
