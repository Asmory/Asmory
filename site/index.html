Assembly package ecosystem

Packages for the instruction level.

Asmory treats ISA versions, CPU extensions, ABI and object format as real dependency-resolution inputs. Reuse machine-level code without erasing the machine contract.

Explore the repositoryContribute

ISA-aware

AVX2, AVX-512, SVE2 and RVV are compatibility constraints, not decorative tags.

Variant-oriented

One package version can carry several machine implementations and let the resolver choose legally.

Assembly-first

The current registry and CLI are static x86-64 ELF programs built with GNU as + ld.

Working CLI

Ask the machine first.

The bootstrap client reads CPUID and XGETBV directly, including OS support for AVX extended register state.
