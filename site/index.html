Assembly package ecosystem

Packages for the instruction level.

Asmory is an experimental package registry for reusable Assembly code. Architecture alone is not enough: ISA versions, extensions, ABI, object format and toolchain constraints are first-class package metadata.

Explore Asmory Contribute

ISA-aware

x86-64-v3, AVX2, FMA, SVE2 and RVV are resolver inputs, not decorative tags.

Variant-oriented

One package version can provide multiple implementations for different machines.

AI-friendly

Machine-readable contracts make low-level libraries easier for humans and coding agents to reuse.

$ asmory add simd-dot

resolving target...
  arch       x86_64
  abi        sysv64
  baseline   x86-64-v3
  features   avx2 fma bmi2

selected:
  simd-dot 0.1.0 / x86_64-avx2-fma
